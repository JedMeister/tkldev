Getting Started
===============

This section will take you from zero to a working TKLDev setup where
you can build and modify TurnKey appliances.

Follow these guides in order:

1) `Setup`_: deploy TKLDev and build your first image (TurnKey Core).
2) `Hello world`_: make your first change using the sandbox and source code.
3) `Git configuration`_: configure Git and understand the TurnKey Git workflow.

Once you've worked through the above, head to the `Reference`_ section to
understand how things work under the hood, or jump straight into the
`Guides`_ for practical how-to instructions.
