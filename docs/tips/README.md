particular order.

- [Interactive testing](./interactive-testing.md): explore and test inside build chroots
- [CLI help](./cli-help.md): self-documenting Makefile and built-in help targets
- [Reducing friction](./reducing-friction.md): shell aliases, CDPATH, SSH key auth and more
- [ISO to USB](./iso-to-usb.md): write a built ISO to a USB drive for testing
